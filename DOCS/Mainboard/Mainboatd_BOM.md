# ThermoSort Main Board

## Clock and Memory

- 1x ABM8-272-T3 crystal
- 1x MX25L3236F flash memory

## Microcontrollers

- 1x ESP32-C3-MINI-1-H4X
- 1x RP2040

## Passive Components

### Capacitors

- 2x 1uF 0402 capacitors
- 18x 100nF 0402 capacitors
- 2x 10uF 0402 capacitors
- 2x 15pF 0402 capacitors
- 2x 47uF 0805 capacitors

### Ferrite Beads

- 1x 0603 ferrite bead

### Resistors

- 2x 27Ω 0402 resistors
- 1x 1kΩ 0402 resistor
- 4x 1.5kΩ 0402 resistors
- 2x 4.7kΩ 0402 resistors
- 2x 5.1kΩ 0402 resistors
- 5x 10kΩ 0402 resistors

## Power Management

- 1x BD33GA3WRFJ-E2 LDO regulator
- 1x BQ24074RGTT battery charger and power management IC

## Connectors

- 1x USB4940-00-A USB-C connector

## User Interface

- 2x 0603 LEDs
- 2x TS40-66-33-BK-160-SMT-TR tactile buttons
